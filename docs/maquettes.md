title: "Maquettes - parcours principal (ordinateur et téléphone)"

> Squelettes de référence pour l'infographe, qui produit les maquettes graphiques définitives (Figma ou équivalent) en respectant la charte de l'ISEP. Les écrans réels de l'application servent de base : ils peuvent être capturés une fois l'application déployée.

# Parcours principal

Connexion → Mes projets → Déposer une idée → Fiche projet (complétude, pièces, soumission) → Décision → Jalons et preuves.

# Fiche projet - ordinateur

```
+--------------------------------------------------------------------+
| [Logo ISEP]  Incubateur du CIAT   Projets  Alertes(2)  Profil  Quitter |
+--------------------------------------------------------------------+
| Titre du projet                      [Modifier] [Compte rendu PDF] |
| (En incubation) · Porteur · cohorte 2026-A · mentor                |
|--------------------------------------------------------------------|
| Décision : Accepté - "motivation..."                               |
|--------------------------------------------------------------------|
| Complétude 100 %  [=====================]   [Soumettre]            |
|--------------------------------------------------------------------|
| Présentation   | Pièces jointes    | Évaluation du comité          |
| Objectifs      | Jalons (statut, preuve, mise à jour)              |
| Suivi 3 / 6 mois | Assistant IA | Commentaires                   |
+--------------------------------------------------------------------+
```

# Fiche projet - téléphone

```
+-----------------------+
| [Logo]            [☰] |
|-----------------------|
| Titre du projet       |
| (En incubation)       |
| Décision ...          |
| Complétude 100 %      |
| [Soumettre]           |
| Présentation          |
| Pièces jointes        |
| Jalons                |
| Commentaires          |
+-----------------------+
```

Sur téléphone, le menu devient un bouton ☰, les grilles passent en une colonne et les tableaux défilent horizontalement.
