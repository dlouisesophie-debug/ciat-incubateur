title: "Répartition des responsabilités de l'équipe"
---

> À compléter avec les noms. Le sujet impose un groupe de trois apprenants ; sans les trois spécialités, les responsabilités doivent être réparties explicitement.

| Membre | Profil | Responsabilités | Livrables portés |
|---|---|---|---|
| [Nom 1] | Développeur | Architecture, authentification, sécurité, base de données, intégration de l'IA, déploiement | Application, code source, schéma, lien de déploiement |
| [Nom 2] | Data analyst | Dictionnaire, qualité et jeu de données, définition des indicateurs, tableau de bord, interprétation | Dictionnaire de données, indicateurs, analyses et recommandations, rapport (partie données) |
| [Nom 3] | Infographe | Logo de l'incubateur, identité visuelle alignée sur la charte ISEP, maquettes, affiche, kit réseaux sociaux | Maquettes, logo, affiche ou flyer, kit de communication |
| Tous | | Cahier des charges, entretiens, tests, rapport, guide, vidéo, journal des prompts | |

**Remarque :** la plateforme fournie reprend les couleurs du logo de l'ISEP (brun `#3E2214`, beige cuivré `#C4926F`). L'infographe doit confirmer ces valeurs avec la charte officielle et fournir le logo propre à l'incubateur.
